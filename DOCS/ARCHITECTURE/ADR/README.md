# Architecture Decision Records

**Status:** Live · **Date:** 2026-10-12 · **Owner:** Backend/Systems Engineer

An ADR records the technical reasoning behind a decision in the Decision Log. The decision log holds the outcome and status. The ADR holds context, options and consequences. Format: Context, Decision, Alternatives, Consequences, Status. ADRs are numbered and never renumbered.
