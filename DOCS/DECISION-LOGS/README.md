# DECISION-LOGS

**Status:** Live · **Date:** 2026-10-12 · **Owner:** Product Manager

## What this folder is for

The record of what was decided, what is still open, what was asked and answered, and what was discussed in meetings. Start with the decision log. Everything else here is evidence or history.

## Files

| File | Role | Status |
|---|---|---|
| `PM-DECISION-LOG-AND-ROADMAP.md` | Decision log (D-), open-issue register (OI-), risks (RISK-), scope tiers | **Canonical** |
| `QA-LOG.md` | Every question put to the sponsor, its options, recommendation and answer | Live, appended each round |
| `MEETING-MINUTES-02-Systems-Scope.md` | Minutes of the systems-scope meeting with the phase 1 respondents | History |
| `software-engineer-questions.md` | Earlier four-question round (programme model, stack, seat hold, booking window) | History; answers carried into D-001 to D-004 |
| `presentation/` | Decision brief deck for the sponsor | Supporting (see its README) |

## Rules

- Decisions are written in the log before they are used in documents.
- Questions are logged in `QA-LOG.md` before they are asked (D-026).
- Where minutes and the log disagree, the log wins (`CONVENTIONS/README.md` §1).
