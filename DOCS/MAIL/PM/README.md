# MAIL/PM

**Status:** Live mirror · **Date:** 2026-10-12 · **Owner:** Product Manager (`vlthrlab-pm@agentmail.to`)

## What this folder is for

One markdown file per email thread, held by the PM role (`THREAD-<id>-<TOPIC>.md`). Replies are appended. Threads are the record of who was asked what and when. The decision log records the outcome; the thread records the exchange.

## Rules

- No secrets in mail or in these files.
- Each thread carries its entity ID (for example OI-001) in the subject grammar defined in `AGENT-COMMUNICATIONS-WORKFLOW.md`.
- Answers that become decisions are cited in the decision log with the thread ID.
