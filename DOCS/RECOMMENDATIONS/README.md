# RECOMMENDATIONS

**Status:** Live · **Date:** 2026-10-12 · **Owner:** Product Manager

## What this folder is for

For every open issue, a recommendation: what we propose, who decides, what gate it blocks, and which document it affects. Recommendations are advice, not decisions. A decision is recorded only in the decision log.

## Files

| File | Contents |
|---|---|
| `OPEN-ISSUE-RECOMMENDATIONS.md` | Recommendation for every open issue OI-001 to OI-040 and the reasoning behind the new stack and vendor items |

## Rules

- A recommendation changes status only when the log changes status.
- Each row names the decision owner. The PM does not decide domain or sponsor questions (D-012 for respondents, sponsor for policy).
- When a recommendation is accepted, the row is updated with the D- entry it produced.
