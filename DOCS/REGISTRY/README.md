# REGISTRY

**Status:** Live · **Date:** 2026-10-12 · **Owner:** Product Manager (registry authority)

## What this folder is for

`team-registry.yaml` is the machine-readable record of who is on the team: one profile per agent or person, their lane, their mailbox role and the governance model (sponsor, PM, lanes, delivery flow). Changes flow through a decision entry (D-016).

## Rules

- Do not put credentials or API keys in the registry. Mailbox keys live in the environment (see the mail protocol).
- A role change updates the registry and the RACI in `GOVERNANCE/MANAGEMENT-SYSTEM.md`.
